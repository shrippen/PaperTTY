RefreshRefresh

Only redraw what changed

Nur neu zeichnen, was sich geändert hat

PaperTTY reads the console as text, compares it with the previous frame and finds the lines that differ. On panels with partial refresh only those bands go to the display, so typing a command does not flash the whole screen.

PaperTTY liest die Konsole als Text, vergleicht sie mit dem vorherigen Bild und findet die Zeilen, die sich unterscheiden. Auf Panels mit partiellem Refresh gehen nur diese Bänder ans Display, sodass ein getippter Befehl nicht den ganzen Bildschirm blinken lässt.

  • Changed lines are merged into blocks, so a few neighbouring edits become one update
  • The cursor is part of the diff: underscore, block or none, chosen with --cursor
  • --nopartial forces full updates on panels where partial refresh looks poor
  • For VNC and framebuffer input, --fullevery sets how many partial updates run before a full one
  • Geänderte Zeilen werden zu Blöcken zusammengefasst, mehrere benachbarte Änderungen ergeben also ein Update
  • Der Cursor ist Teil des Vergleichs: Unterstrich, Block oder keiner, gewählt mit --cursor
  • --nopartial erzwingt volle Updates auf Panels, bei denen partieller Refresh schlecht aussieht
  • Bei VNC- und Framebuffer-Eingabe legt --fullevery fest, wie viele partielle Updates vor einem vollen laufen
SpeedTempo

Fast on IT8951 HD panels

Schnell auf IT8951-HD-Panels

Release 1.0.0 was measured on real hardware: a 1872×1404 panel on a Pi Zero 2 W. Real SPI speed through --mhz and a numpy fast path for 1-bit packing cut a full A2 refresh from 3.4 s to 0.6 s and a partial line update from 1.5 s to 0.03 s.

Release 1.0.0 wurde auf echter Hardware gemessen: ein 1872×1404-Panel an einem Pi Zero 2 W. Die echte SPI-Geschwindigkeit über --mhz und ein numpy-Schnellpfad fürs 1-Bit-Packen senken einen vollen A2-Refresh von 3,4 s auf 0,6 s und ein partielles Zeilen-Update von 1,5 s auf 0,03 s.

  • --mhz 12 is verified stable, 16 MHz is not
  • Packing a full frame dropped from 1.6 s to 0.02 s
  • BUSY and LUT waits have timeouts, so a wedged controller restarts the service instead of hanging
  • --disable_a2 and --disable_1bpp switch the fast paths off if a panel misbehaves
  • --mhz 12 ist als stabil geprüft, 16 MHz nicht
  • Das Packen eines vollen Bildes sank von 1,6 s auf 0,02 s
  • BUSY- und LUT-Wartezeiten haben Timeouts, ein hängender Controller startet den Dienst also neu statt zu blockieren
  • --disable_a2 und --disable_1bpp schalten die Schnellpfade ab, falls ein Panel sich seltsam verhält

How it works

So funktioniert es

PaperTTY keeps a Pillow image of the current screen and only sends what changed. The drivers come from the Waveshare demos, with a common base class so the panels share most of their code.

PaperTTY hält ein Pillow-Bild des aktuellen Bildschirms und schickt nur, was sich geändert hat. Die Treiber stammen aus den Waveshare-Demos und teilen sich eine gemeinsame Basisklasse, sodass die Panels den größten Teil ihres Codes gemeinsam haben.

tty · VNC · fb · imageConsole text, remote desktop, framebuffer or a pictureKonsolentext, Remote-Desktop, Framebuffer oder ein Bild
PaperTTYRenders with Pillow and finds the dirty regionsRendert mit Pillow und findet die geänderten Bereiche
Display driverDisplay-TreiberOne class per panel: init, LUT, partial or full refreshEine Klasse pro Panel: Init, LUT, partieller oder voller Refresh
SPI + GPIOspidev and gpiozero with lgpiospidev und gpiozero mit lgpio
  • Text is read with the console encoding, latin_1 by default and changeable with --encoding; systems with /dev/vcsu get Unicode
  • --rows and --cols set the tty size, or --autofit fits it to the font and panel
  • --no-rotate (alias --portrait) renders along the native panel axes instead of rotating the text by 90 degrees
  • --interactive lets you type on the panel without a separate keyboard session
  • Text wird mit der Konsolenkodierung gelesen, standardmäßig latin_1 und änderbar mit --encoding; Systeme mit /dev/vcsu bekommen Unicode
  • --rows und --cols setzen die TTY-Größe, oder --autofit passt sie an Schrift und Panel an
  • --no-rotate (Alias --portrait) rendert entlang der nativen Panelachsen, statt den Text um 90 Grad zu drehen
  • --interactive erlaubt Eingaben auf dem Panel ohne separate Tastatursitzung

Install

Installation

  1. Enable SPI with raspi-config. The Lite installer can do this for you.
  2. Run the installer one-liner from the box above: venv only if you just want the command, full Lite setup for a Pi that should boot straight into PaperTTY, or the desktop installer for XFCE.
  3. Answer the prompts: GPIO library, autologin, panel driver, orientation and font size, boot method.
  4. Reboot. The panel shows the console; run sudo papertty --driver <name> scrub once if you see ghosting.
  1. Aktiviere SPI mit raspi-config. Der Lite-Installer kann das für dich erledigen.
  2. Führe den Installer-Einzeiler aus der Box oben aus: nur venv, wenn du bloß den Befehl willst, komplette Lite-Einrichtung für einen Pi, der direkt in PaperTTY startet, oder den Desktop-Installer für XFCE.
  3. Beantworte die Fragen: GPIO-Bibliothek, Autologin, Panel-Treiber, Ausrichtung und Schriftgröße, Startmethode.
  4. Starte neu. Das Panel zeigt die Konsole; bei Ghosting einmal sudo papertty --driver <Name> scrub ausführen.

Files stay in your home directory: the venv in ~/.local/share/papertty/venv, fonts in ~/.local/share/fonts/papertty-init/ and the start script in ~/.local/bin/papertty-init/startpapertty.sh. The boot service is papertty.service (systemd, recommended) or an @reboot crontab line. Environment variables PAPERTTTY_REPO_URL, PAPERTTTY_REF and PAPERTTTY_SRC change the source of the curl installers.

Die Dateien bleiben im Home-Verzeichnis: das venv in ~/.local/share/papertty/venv, Schriften in ~/.local/share/fonts/papertty-init/ und das Startskript in ~/.local/bin/papertty-init/startpapertty.sh. Der Boot-Dienst ist papertty.service (systemd, empfohlen) oder eine @reboot-Zeile in der crontab. Die Umgebungsvariablen PAPERTTTY_REPO_URL, PAPERTTTY_REF und PAPERTTTY_SRC ändern die Quelle der curl-Installer.

Usage

Nutzung

After install, the CLI is ready. Most commands need sudo because they talk to the console device and to SPI and GPIO.

Nach der Installation ist die CLI einsatzbereit. Die meisten Befehle brauchen sudo, weil sie mit dem Konsolengerät sowie mit SPI und GPIO sprechen.

# terminal on a 2.13″ HAT sudo papertty --driver EPD2in13 terminal --autofit # IT8951 HD panel: VCOM from the FPC sticker, real SPI speed sudo papertty --driver IT8951 --vcom 1450 --mhz 12 terminal --autofit # clear ghosting sudo papertty --driver EPD2in13 scrub # VNC (pip install 'papertty[vnc]') sudo papertty --driver EPD2in13 vnc --host localhost --display 0 # show a picture, or pipe text in sudo papertty --driver EPD2in13 image --image photo.png echo "hello" | sudo papertty --driver EPD2in13 stdin

Questions

Fragen

Which displays and which Pi do I need?Welche Displays und welchen Pi brauche ich?

Any Raspberry Pi with SPI. The 1.0.0 release was verified with an IT8951 1872×1404 panel on a Pi Zero 2 W. Raspberry Pi OS Bookworm or Trixie is recommended, with Python 3.11 or newer.

Jeder Raspberry Pi mit SPI. Release 1.0.0 wurde mit einem IT8951-Panel (1872×1404) an einem Pi Zero 2 W geprüft. Empfohlen sind Raspberry Pi OS Bookworm oder Trixie mit Python 3.11 oder neuer.

What does experimental mean?Was bedeutet experimentell?

Seventeen drivers are new ports of the Waveshare demos (2.13″ V3 and V4, 7.5″ HD, 4.01″ 7-color and others) that have not run on real panels. They print a warning at start. The classic drivers from upstream are mostly untested by me, too; some were tested by the upstream authors years ago.

Siebzehn Treiber sind neue Portierungen der Waveshare-Demos (2,13″ V3 und V4, 7,5″ HD, 4,01″ 7-farbig und weitere), die noch nie auf echten Panels gelaufen sind. Sie geben beim Start eine Warnung aus. Auch die klassischen Treiber aus dem Original sind von mir größtenteils ungetestet; einige haben die Original-Autoren vor Jahren getestet.

How do I wire the panel?Wie verdrahte ich das Panel?

Most Waveshare HATs sit on the Pi header and use the same BCM pins: RST 17, DC 25, CS 8, BUSY 24, plus SPI0 for MOSI and SCLK. Enable SPI with raspi-config. For IT8951 boards, set the DIP switch to SPI (some HATs also work over USB) and pass --vcom from the FPC sticker. Use a power supply that can handle the panel's peak current, especially for larger panels.

Die meisten Waveshare-HATs sitzen auf der Pi-Leiste und nutzen dieselben BCM-Pins: RST 17, DC 25, CS 8, BUSY 24 sowie SPI0 für MOSI und SCLK. Aktiviere SPI mit raspi-config. Bei IT8951-Boards stellst du den DIP-Schalter auf SPI (manche HATs funktionieren auch per USB) und übergibst --vcom vom FPC-Aufkleber. Nutze ein Netzteil, das den Spitzenstrom des Panels verkraftet, vor allem bei größeren Panels.

I see GPIO busy on an IT8951 panelIch sehe GPIO busy bei einem IT8951-Panel

The driver toggles chip-select by hand, so the kernel must not own GPIO 8. Add dtoverlay=spi0-0cs to /boot/firmware/config.txt and reboot.

Der Treiber schaltet Chip-Select von Hand, der Kernel darf GPIO 8 also nicht besitzen. Trage dtoverlay=spi0-0cs in /boot/firmware/config.txt ein und starte neu.

The text is rotated by 90 degreesDer Text ist um 90 Grad gedreht

By default text is rotated to suit portrait panels. IT8951 HD panels are landscape natively, so add --no-rotate. Use --flipx or --flipy if the mount is upside down.

Standardmäßig wird der Text für Hochformat-Panels gedreht. IT8951-HD-Panels sind von Haus aus Querformat, ergänze also --no-rotate. Bei kopfstehender Montage helfen --flipx oder --flipy.

The panel shows ghostingDas Panel zeigt Ghosting

Run sudo papertty --driver <name> scrub. It works with all drivers, including IT8951 (which also needs --vcom). --scrub on terminal does the same at startup.

Führe sudo papertty --driver <Name> scrub aus. Das funktioniert mit allen Treibern, auch IT8951 (das zusätzlich --vcom braucht). --scrub bei terminal macht dasselbe beim Start.

Is this an official Waveshare or upstream project?Ist das ein offizielles Waveshare- oder Upstream-Projekt?

No. It is a personal fork of joukos/PaperTTY, updated for current Raspberry Pi OS, with installers based on papertty-init. Application code was originally CC0; the display drivers under papertty/drivers/ are GPL-3.0.

Nein. Es ist ein persönlicher Fork von joukos/PaperTTY, aktualisiert für aktuelles Raspberry Pi OS, mit Installern auf Basis von papertty-init. Der Anwendungscode war ursprünglich CC0; die Display-Treiber unter papertty/drivers/ stehen unter GPL-3.0.
