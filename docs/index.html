PaperTTY

Render a Linux terminal on affordable SPI e-ink displays. Vibe-coded fork, modernized for current Raspberry Pi OS.

Quick install (venv only)
bash -c "$(curl -fsSL https://raw.githubusercontent.com/shrippen/PaperTTY/main/install/simple.sh)"
Full Lite setup (SPI, autologin, boot service)
bash -c "$(curl -fsSL https://raw.githubusercontent.com/shrippen/PaperTTY/main/install/cli.sh)"
Also: Desktop / XFCE installer
GitHub Wiki

Features

Everything you need to run a terminal on e-ink.

🖥️

Virtual Console

Mirror a Linux tty directly to the e-ink panel with partial refresh where supported.

📡

VNC Support

Display a remote desktop session on e-ink. Great for headless setups with a graphical environment.

⚡

Modern Stack

Python 3.11+, Pillow 10+, click 8, spidev, gpiozero/lgpio. Installs cleanly on Bookworm & Trixie.

🔧

One-liner Installers

papertty-init-style prompts: pick your panel, GPIO backend, and boot method. Works from curl.

🖼️

40+ Display Drivers

From 1.54″ to 10.3″ — including IT8951 HD boards. Experimental V2/V3/V4/HD ports included.

🧹

Panel Scrub

Built-in scrub command to clear ghosting. Works with all drivers including IT8951.

Usage

After install, the CLI is ready.

sudo papertty --driver EPD2in13 terminal --autofit sudo papertty --driver IT8951 --vcom 1450 terminal --autofit sudo papertty --driver EPD2in13 scrub
