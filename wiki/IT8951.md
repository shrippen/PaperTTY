# IT8951

**IT8951 HD HAT (6" / 7.8" / 9.7" / 10.3" / …)**

A generic driver for displays that use a IT8951 controller board.

## Specs (as used by PaperTTY)

| | |
|--|--|
| Driver name | `IT8951` |
| Resolution | Auto-detected from the controller (e.g. 800×600, 1872×1404, …) |
| Partial refresh | Yes |
| Color channels | Grayscale hardware; PaperTTY uses 1-bit mono |
| Interface | SPI (or USB on some HATs) |

## Usage

```bash
sudo papertty --driver IT8951 --vcom 1450 terminal --autofit
```

Installer panel list entry: `IT8951`.

Orientation: `--no-rotate` (alias: `--portrait` from upstream) renders text along the panel's native framebuffer axes without a 90 degree rotation. On IT8951 HD panels the native layout is landscape, so `--no-rotate` reads as landscape; without the flag the text is rotated 90 degrees. Add `--flipx` / `--flipy` if your mounting is upside down or mirrored.

Scrub / clear:

```bash
sudo papertty --driver IT8951 --vcom 1450 scrub
```

For IT8951, VCOM is required (top-level `--vcom`). Read the millivolt value from the FPC label.

## Hardware notes

Generic IT8951 driver: resolution and LUT are read from the controller. Set `--vcom` from the FPC sticker (e.g. -1.45V → 1450). DIP switch must be SPI (or use USB). The driver toggles CS manually across multi-transfer commands, so the kernel must not own GPIO 8: add `dtoverlay=spi0-0cs` to `/boot/firmware/config.txt` and reboot. Without it, gpiozero/lgpio fails with `GPIO busy`.

[Waveshare wiki](https://www.waveshare.com/wiki/7.8inch_e-Paper_HAT)

## Pinout (typical Waveshare HAT, BCM)

| Signal | BCM |
|--------|-----|
| RST | 17 |
| DC | 25 |
| CS | 8 |
| BUSY | 24 |
| MOSI / SCLK | SPI0 |

Always enable SPI and use a power supply that can handle the panel's peak current.

## Status

Untested hardware may need LUT or init tweaks. Please open an issue if your revision misbehaves with this driver name.
